# Card Game

Card game similar to UNO or Lucky Eights for a web site. (UI in czech language)

## Description

Card game designed in HTML with CSS styling and logic written in JS. Light front-end application used to encode an author game eternally.

## Getting Started

### Dependencies

* Runs on every modern browser

### Executing program

* Programm runs on [GitHub Pages](https://terahouska.github.io/Card-Game/)
* Alternatively you can download the project and open "index.html" file in your browser

### Missing functionalities

New functionalities will be added continuously mostly  including:
* New card effects
* Better UI
* More possibilities for settings like number of players and cards
